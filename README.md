[`docs/ТЗ-заказчика.md`](./docs/ТЗ-заказчика.md) и собрал работающий интерактивный прототип.

## Что сделано

### 1. Промо-сайт
- Hero «Играй. Побеждай. Зарабатывай.», живой телефон с экраном входа.
- Блок возможностей (честный драфт, выбор сервера, боты-лобби, войс, античит, призы).
- Путь игрока из 4 шагов, экономика призов, блок для рекламодателей/партнёров.
- CTA «Открыть приложение» переключает в интерактивный прототип.

### 2. Мобильное приложение — 7 экранов макета

| # | Экран | Что работает |
|---|-------|--------------|
| 1 | Вход | Привязка Game ID, вход через Telegram / VK / Google / Facebook, плашка античита |
| 2 | Заполните профиль | 3 шага: фото+ник+возраст+пол+ранг; мультироли; **выбор серверов/регионов**; «О себе»; любимые герои; загрузка скриншота с проверкой ботом |
| 3 | Главная | Чистый старт: Game ID, аватар, ELO/роль (появляются после заполнения анкеты), пустые состояния с подсказками, доп. слот за 150 ₽, привязка соцсетей за 30 ₽, партнёрский баннер |
| 4 | Профиль игрока | Профиль в развёрнутом виде + кнопка настроек (редактирование анкеты) |
| 5 | Captain's Draft | Два капитана, монетка (кто первый), таймер хода, фильтры по ролям, пул из 8 игроков с винрейтом/KDA/ролью, карточка игрока, поочерёдный выбор и заполнение слотов команд |
| 6 | Матч готов | ID лобби с копированием, голосовой чат 5/5 с мутами и индикаторами речи, микрофон/выход, блок авто-парсинга скриншота |
| 7 | Таблица лидеров | Вкладки Сезон / Месяц / Друзья, обычная и про-лига, призы топ-3, ELO, короны про-игроков |

Без входа профиль хранится в `localStorage`, после входа по почте — в Supabase.
Старт всегда чистый: все данные вводит сам пользователь через анкету, кнопка
«Очистить анкету» внизу анкеты сбрасывает всё. На десктопе есть боковая панель
быстрого перехода по всем экранам, на мобильном — нижняя навигация. Приложение
адаптивно: на телефоне занимает весь экран и использует системный статус-бар
устройства, на десктопе показывается нейтральной колонкой без фальшивой «шторки».
Данные других игроков (драфт-пул, матч, рейтинг) — демо-заглушки с пометкой,
пока нет серверной части (см. roadmap).

## Запуск

```bash
cd app
npm install
npm run dev
```

Откройте `http://localhost:5173/` (в Arena — live preview на порту 5173).
Сборка: `npm run build`, предпросмотр сборки: `npm run preview`.

Стек: React 18 + Vite 6, CSS без фреймворков, иконки `lucide-react`,
шрифты `Unbounded` и `Inter` (устанавливаются из npm, без внешних CDN).

## Границы прототипа

Это front-end прототип по макету: нет реального сервера, OAuth соцсетей, игровых ботов,
голосовой связи и платежей — соответствующие блоки реализованы как рабочие UI-сценарии
с демо-данными. Это соответствует статусу презентации заказчика («не рабочая история,
а показной вариант»).

## Подключение Supabase: аккаунт, профиль и медиа

В репозитории подготовлена интеграция входа по email/паролю, сохранения анкеты
и загрузки фото и скриншотов. Она отключена, пока не заданы переменные окружения;
без них приложение остаётся демонстрационным прототипом на `localStorage`.

1. Создайте проект в Supabase и примените **все** SQL из `supabase/migrations/`
   через SQL Editor или Supabase CLI, по порядку:
   - `20261028000000_profiles.sql` — таблица `player_profiles` с RLS:
     пользователь читает и изменяет только свою анкету;
   - `20261028230000_profile_media_storage.sql` — бакеты `avatars` и `screenshots`
     (публичное чтение, запись только в свою папку) + колонки `avatar_url`,
     `screenshot_urls`.
   - `20261028234500_admins_and_persistent_socials.sql` — колонки `socials`,
     `extra_slots`, таблица `admins` и чтение всех анкет для админов.
2. Включите Email provider в Auth. Если включено подтверждение почты, добавьте URL
   приложения в настройки redirect URL и настройте доставку писем.
3. Скопируйте `app/.env.example` в `app/.env` и укажите URL проекта и
   **публичный publishable/anon key**. Секретный ключ или `service_role`
   в браузере использовать нельзя. Перезапустите Vite.
4. Войдите по почте на экране входа, заполните анкету, загрузите фото
   (JPG/PNG/WebP/GIF до 5 МБ) и до 4 скриншотов статистики, сохраните.
   Для нового аккаунта может потребоваться подтвердить email.

Без входа загрузки фото и скриншотов работают как локальный предпросмотр
и не покидают браузер. Привязки соцсетей и доп. слоты сохраняются в базе
(настоящей оплаты пока нет — это прототип покупок). Рейтинг, верификация,
драфт, матчи и голосовой чат по-прежнему демонстрационные; социальные кнопки
не выполняют OAuth. Для этих функций нужны серверная логика и интеграции.
Не используйте прототип как production-систему без настройки защиты,
модерации и проверки политик.

## Админка

Экран «Админка» (кнопка ADMIN на главной, пункт в навигации) виден только
администраторам. Админ видит всех пользователей: статистику, поиск по нику
и Game ID, полные анкеты с фото и скриншотами. Обычные пользователи видят
только свой собственный профиль.

Назначить админа может только владелец базы — клиентским кодом это сделать
нельзя (политик на запись в `admins` нет). Зарегистрируйтесь в приложении,
затем выполните в SQL Editor Supabase:

```sql
insert into public.admins (user_id)
select id from auth.users where email = 'YOU@example.com'
on conflict do nothing;
```

После этого перезайдите в приложение — появится доступ в админку.
