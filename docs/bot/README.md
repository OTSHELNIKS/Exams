# Аватарка и профиль бота

Бот: [@name_mlbb_bot](https://t.me/name_mlbb_bot) (webhook на Edge Function `telegram-bot`).

## Файлы

| Файл | Размер | Зачем |
| --- | --- | --- |
| `docs/bot/avatar.png` | 1600×1600, ~780 КБ | мастер-файл для @BotFather (`/setuserpic`) |
| `app/public/bot-avatar.jpg` | 512×512, ~24 КБ | картинка-визитка в приветствии бота; попадает на сайт как `/bot-avatar.jpg` |

Обе картинки — один и тот же рисунок: оранжевый градиентный круг (#FF6A2B → #FF3D00)
со свечением, пять наклонных тёмных полос и белый вордмарк **NAME** на почти чёрном фоне.

## Что делает бот сам

`GET …/telegram-bot?setup=SETUP_SECRET` ставит:

- webhook и список команд (`setWebhook`, `setMyCommands`);
- описание профиля (`setMyDescription`) и короткое описание (`setMyShortDescription`);
- по `/start` новичку уходит фото-визитка с подписью, затем шаги привязки и кнопка
  «🎮 Открыть приложение». Привязанному аккаунту — приветствие по нику и та же кнопка.

## Что нужно сделать руками (один раз)

1. Открыть @BotFather → `/setuserpic` → выбрать `@name_mlbb_bot` → отправить
   `docs/bot/avatar.png` (Telegram обрежет в круг сам — рисунок для этого и сделан
   квадратным, важное в центре).
2. Если картинки нет под рукой: открыть с телефона
   <https://otshelniks.github.io/Exams/bot-avatar.jpg>, сохранить в галерею и
   отправить этот файл в BotFather.

Bot API не умеет менять аватарку бота — `sendPhoto` с URL отправляет картинку
в чат, а не в профиль. Поэтому шаг 1 остаётся ручным.

## Если приветствие без картинки

Бот пробует `sendPhoto` с `https://otshelniks.github.io/Exams/bot-avatar.jpg`
(собирается из секрета `APP_PUBLIC_URL`) и при ошибке тихо откатывается на
текстовое приветствие. Проверка:

1. `…/telegram-bot?health=1` — функция жива;
2. ссылка на `bot-avatar.jpg` открывается в браузере (после деплоя Pages);
3. `/start` в боте — должна прийти картинка с подписью.
