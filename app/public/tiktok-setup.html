3App review → Required information

Текст для ревьюера
NAME is a matchmaking web app for Mobile Legends: Bang Bang players. TikTok Login Kit is used as a social link on a player's profile: after sign-in with TikTok we request only user.info.basic to read the display name (and avatar URL when provided) and show it in the profile as a verified social account. We do not post or upload content, do not access videos, followers or messages, and do not store tokens — the access token is used once on our server to fetch the profile and then discarded. Only the display name is stored in the player's profile. Website: https://otshelniks.github.io/Exams/ Privacy Policy: https://otshelniks.github.io/Exams/privacy.html Terms of Service: https://otshelniks.github.io/Exams/terms.html Scopes used: user.info.basic (Login Kit only).

5Sandbox — без этого вход не пустит

Переключись на вкладку Sandbox сверху и добавь свой TikTok-аккаунт в тестовые пользователи. Пока приложение не одобрено, авторизация работает только у них.

Затем проверь привязку: открыть сайт → войти → Профиль → «+» → TikTok → «Войти через TikTok» → «Разрешить».
