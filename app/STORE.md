# Тексты и графика для магазинов (App Store / Google Play)

Всё, что нужно вставить в консоли. Меняй под себя — длины полей проверены.

## Google Play

**Название (до 30):**

```
NAME — драфты и рейтинг MLBB
```

**Короткое описание (до 80):**

```
Драфт на 5 героев, рейтинг игроков и статистика MLBB. Заходи через игровой аккаунт.
```

**Полное описание (до 4000):**

```
NAME — приложение для тех, кто играет в Mobile Legends: Bang Bang и хочет драфтить осознанно, а не «как получится».

ЧТО ВНУТРИ

• Драфт на 5 героев. Приложение подсказывает роли и баны, собирает составы двух команд и показывает, чего не хватает каждой стороне.
• Рейтинг игроков. Позиции, очки, винрейт и КДА — по подтверждённым игровым аккаунтам.
• Карточка игрока. Что за герои в пуле, на каких позициях играет, как меняется форма в последних матчах.
• Ростер героев с ролями и сложностью: ищи по имени и фильтруй по позиции.
• Привязка игрового аккаунта. Указываешь Game ID и сервер, подтверждаешь владение кодом из внутриигровой почты MLBB — и статистика подтягивается сама. Код нужен, чтобы никто не мог выдать себя за другого игрока.
• Вход через Google, Telegram-бота или игровой аккаунт. Один аккаунт — телефон и компьютер.

ЧЕСТНО О ЦИФРАХ

Если игра не отдаёт статистику, приложение так и пишет и показывает «—», а не выдуманные числа. Винрейт и КДА считаются по последним матчам и обновляются кнопкой «Обновить».

ЧЕГО НЕТ

• Нет рекламы.
• Нет платных подписок.
• Нет продажи данных и передачи их рекламным сетям.

КОМУ ПОДХОДИТ

Игрокам MLBB, которые собирают команды на турниры и скримы, капитанам и всем, кто хочет видеть свой прогресс, а не только звёзды в профиле.

NAME не связан с Moonton. Mobile Legends: Bang Bang — товарный знак Moonton.
```

```
Первый релиз: драфт на 5 героев, рейтинг игроков, карточки с винрейтом и КДА, ростер героев, вход через Google, Telegram и игровой аккаунт.
```

**Категория:** Entertainment (или Tools, если хочется меньше конкуренции).
**Теги:** moba, драфт, киберспорт, статистика.
**Контактный e-mail:** тот же, что в `app/public/privacy.html`.

**Графика:**

| Файл | Размер | Куда |
| --- | --- | --- |
| `app/resources/icon.png` | 1024×1024 | иконка приложения (Play сожмёт до 512×512) |
| `app/resources/feature-graphic.png` | 1024×500 | Feature graphic |
| 2–8 скриншотов с телефона | 1080×1920 или 1440×2560 | Screenshots |

Скриншоты снимаются с живого приложения: главная, драфт, рейтинг, карточка
игрока. Никакого мокапа с ноутбуком не нужно — Play любит реальные экраны.

**Data safety (форма Play):**

| Вопрос | Ответ |
| --- | --- |
| Собирает ли приложение данные? | Да |
| Передаются ли данные третьим лицам? | Нет (кроме обработчиков: Supabase — хостинг БД, Google/Telegram — вход, если сам привязал) |
| Шифрование при передаче | Да |
| Пользователь может запросить удаление | Да — через поддержку в приложении или e-mail |
| Данные | Адрес e-mail, имя/ник, фото профиля (аватар), идентификаторы аккаунта, игровой профиль (Game ID, сервер), действия в приложении |
| Для чего | Работа аккаунта, отображение профиля и рейтинга, поддержка |
| Обязательность | Всё, кроме фото и соцсетей, обязательно для работы аккаунта |

**App content:**

- Реклама: **нет**.
- Покупки в приложении: **нет**.
- Целевая аудитория: **13+** (не «для детей»).
- Контент-рейтинг: пройти опрос IARC — насилие/кровь/азартные игры — «нет».
- Новости/политика: не применимо.
- COVID-приложения: не применимо.
