# Задание 4 — авторизация и администрирование

## Запуск

Из корня репозитория:

```bash
python3 solutions/task4_auth_api/app.py
```

Откройте `http://127.0.0.1:8000`. Проект не требует сторонних Python-библиотек; SQLite создаётся при первом запуске в `exam_app.sqlite3` рядом с `app.py`.

Демонстрационные учётные записи:

- администратор: `admin` / `Admin123!`
- пользователь: `user` / `User123!`

В реальном экзаменационном стенде замените пароли переменными окружения `EXAM_ADMIN_PASSWORD` и `EXAM_USER_PASSWORD` до первого запуска. Пароль в SQLite хранится как PBKDF2-HMAC-SHA256 с солью, не в открытом виде.

## Реализовано

- обязательные поля логина и пароля, роли «Администратор» и «Пользователь»;
- интерактивная капча-пазл 3×3 на основе приложенных изображений; фрагменты можно переставлять кликами или перетаскиванием, а решение проверяется на сервере;
- три последовательные ошибки капчи или пароля блокируют известную учётную запись; успешный вход сбрасывает счётчик;
- после успешной авторизации выводится сообщение «Вы успешно авторизовались»;
- рабочий стол и выход из системы;
- панель администратора `/admin/users`: добавление пользователя с проверкой уникальности логина, изменение логина/роли/пароля и снятие блокировки;
- блокировка, счётчик ошибок и учётные записи хранятся в SQLite.

Это учебная демонстрационная реализация. Сессии находятся в памяти процесса; для промышленной эксплуатации нужно добавить HTTPS, CSRF-защиту и постоянное хранилище сессий.
