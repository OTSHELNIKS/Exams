## Быстрые команды

Пересобрать полный PDF и DOCX (из корня репозитория; зависимости — `solutions/requirements.txt`):

```bash
python3 -m pip install -r solutions/requirements.txt
python3 solutions/build_full_step_report.py
```

Для PDF-генератора также нужен установленный шрифт DejaVu Sans Mono/DejaVu Sans (путь по умолчанию — `/usr/share/fonts/truetype/dejavu/`).

Создать/перезагрузить БД заданий 1–3:

```bash
python3 solutions/task2_database/seed.py
```

Запустить приложение заданий 4–5:

```bash
python3 solutions/task4_auth_api/app.py
```

Проверить API и блокировку:

```bash
python3 -m unittest discover -s solutions/task4_auth_api/tests -v
```

Повторно построить очищенную таблицу и анализ (нужен `openpyxl`):

```bash
python3 solutions/task7_analysis/clean_data.py
```
